# BGM の置き場所

このフォルダに BGM ファイル（`.mp3` / `.m4a` / `.wav`）を置き、`make.py --bgm assets/bgm/xxx.mp3` で使います。

## 重要：必ず利用条件を確認
- **商用利用OK・TikTok投稿OK** の音源だけを使ってください（フリー配布でもクレジット表記が必要な場合があります）。
- 市販曲・アーティスト楽曲の焼き込みは著作権侵害になります。**やめてください**。
- **おすすめは「焼き込まず、TikTokアプリ内のトレンド音源／商用楽曲ライブラリを当てる」運用**です。
  リーチ（おすすめ表示）にも著作権にも有利です。詳しくは [../../docs/workflow.md](../../docs/workflow.md) の「[3] 音を付ける」。

フリーBGMの入手先の例（各サイトの規約を必ず確認）:
- YouTube オーディオ ライブラリ
- DOVA-SYNDROME
- 甘茶の音楽工房
- Pixabay Music

※ ライセンスの都合上、音源ファイルはこのリポジトリには含めていません（`.gitignore` 済み）。
