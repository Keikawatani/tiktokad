# TikTok BGM：流行り系サウンド30選＋「今週のトレンド音源」の探し方

## 大前提（これだけは守る）
1. **BGMは動画に焼き込まず、TikTokアプリ内で付ける**。理由は2つ：
   - **リーチが伸びる**（トレンド音源は「おすすめ」に乗りやすい）
   - **著作権が安全**（アプリ内の楽曲は投稿利用が許諾されている）
2. **トレンドは週単位で変わる**。下のリストは「候補」。**投稿直前に、アプリ内で今伸びている音源を必ず確認**して差し替えるのが正解。
3. 占い動画に合うのは **①可愛い(kawaii)系 ②エモ・おしゃれ系 ③ミステリアス系**。テンポは中〜スロー、静止画に声（ナレーション）を乗せない日はBGMだけでOK。

---

## ★最重要：今“実際に”流行っている音源の探し方（これが本体）
リストを配るより、これを毎回やる方が確実です。

1. TikTokの**楽曲追加画面**で「**おすすめ / 急上昇（トレンド）**」タブを見る。曲名の横に**↗マーク**が付くのがトレンド音源。
2. 「**占い**」「**星座占い**」で検索し、**伸びている占い動画が使っている音源**をタップ→「この楽曲を使う」。＝勝ってる音を真似る。
3. 気に入った音源は**お気に入り登録**（♡）しておくと、次の投稿で即使える。
4. **同じ音源で連投しすぎない**（3〜4本で替える）。飽き・重複判定の回避になる。

## 占い動画での使い分けメモ
- **総合運・恋愛運ランキング** → ①可愛い系 or ②エモ系（見やすさ重視の中テンポ）
- **金運・仕事運** → ③キャッチー系で軽快に
- **ラッキーカラー・診断** → ①可愛い系（保存されやすい優しい雰囲気）
- **ミステリアスに寄せたい日** → 「占い」「タロット」タグの人気動画が使う**幻想系サウンド**を拝借
