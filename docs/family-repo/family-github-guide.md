# 家族ではじめる GitHub ガイド

家族に配る用のガイドです。GitHub を使ったことがない人向けに書いています。
（Claude ドキュメント版: https://claude.ai/code/artifact/58e2d250-29c1-4be8-85f6-21630d66f871 ）

## GitHub は「消えない共有ノート」です

GitHub は、家族みんなで書き込める 1 冊のノートだと思ってください。もともとはプログラマーが仕事で使う道具ですが、ふつうの文章やメモを置く場所として、そのまま使えます。

紙のノートや LINE との違いは 3 つです。

- **誰が・いつ・どこを書き換えたか**が、すべて自動で記録に残ります
- **間違えて消しても元に戻せます。** 過去のどの時点の状態にも戻せます
- **家族全員が同じ最新版を見ます。**「どれが最新だっけ？」と探す必要がありません

覚える言葉は、さしあたり 2 つだけで足ります。

- **リポジトリ** … ノート 1 冊のこと。家族用に 1 冊だけ作ります
- **コミット** … 「保存」のこと。保存するたびに、履歴が 1 行増えていきます

パソコンに何かをインストールする必要はありません。**ウェブブラウザとスマホだけで全部できます**。

## 家族のノートに何を入れるか

「後で参照したい文字の情報」が向いています。たとえばこんなものです。

| フォルダ | 入れるもの |
|---|---|
| `docs/` | 保険・契約・手続きの覚え書き、ゴミの出し方 |
| `recipes/` | 家のレシピ、味付けのメモ |
| `household/` | 買い物リスト、当番表、年間の予定 |
| `travel/` | 旅行の計画、持ち物リスト |

逆に、**写真や動画、パスワードは向いていません**。理由は後の章で。

## 最初にやる 3 つ

1. **アカウントを作る** — https://github.com/signup でメールアドレスとパスワードを登録。無料です。
2. **2 段階認証（2FA）を設定する** — GitHub では必須です。スマホの認証アプリで QR コードを読み取るだけ。1 分で終わります。
    - 途中で出る**リカバリーコード（16 個の文字列）は必ず保存**してください。スマホをなくしたときに入れる唯一の手段です。
3. **招待メールを受け取る** — 家族のノートに招待されるとメールが届きます。中のボタンを押すと参加完了です。

アカウント名は本名でなくてかまいません。家族が見て分かる名前にしておくと、誰の書き込みか分かりやすいです。

## 書き込み方（ブラウザだけで OK）

難しいソフトは不要です。GitHub のページ上で直接編集して保存できます。

**すでにあるファイルを直すとき**

1. 直したいファイルをクリックして開く
2. 右上の**鉛筆のアイコン**を押す
3. 普通に文章を書き換える
4. 緑の **Commit changes** ボタン → もう一度 **Commit changes** で保存

**新しいメモを作るとき**

1. トップページの **Add file** → **Create new file**
2. 上の欄にファイル名を入力。例: `recipes/カレー.md`（`/` を入れるとフォルダができます）
3. 本文を書いて **Commit changes**

ファイル名は必ず **`.md`** で終わらせてください。見出しや箇条書きがきれいに表示されます。

**覚える書式はこの 3 つだけ**

| 書くと | こうなる |
|---|---|
| `# 見出し` | 大きな見出し |
| `- あいう` | 箇条書き |
| `- [ ] 牛乳を買う` | チェックボックス（押すとチェックできる） |

忘れても問題ありません。普通の文章をそのまま書いてもちゃんと表示されます。

スマホからも同じ手順でできます。ブラウザで github.com を開けば、アプリを入れなくても編集できます。

## 気をつけること

**パスワード・マイナンバー・カード番号は絶対に書かない**
これが一番大事です。GitHub は**一度保存したものが履歴に永久に残る**仕組みなので、後から消しても完全には消せません。パスワードは 1Password や iPhone の「パスワード」アプリへ。

**非公開（Private）のまま使う**
URL を知っていても、招待された家族以外は見られません。設定画面の公開関連の項目は触らないでください。

**写真や動画は入れない**
容量がすぐにいっぱいになります。Google フォトなどのリンクをメモに貼るだけにしましょう。

**壊れる心配はしなくていい**
間違えて消しても、変なところを触っても、全部元に戻せます。気軽に書いて大丈夫です。

## 困ったとき

| こんなとき | どうする |
|---|---|
| 間違えて消した・壊した気がする | 慣れている人に言う。履歴から元に戻せます |
| 英語の画面が出てくる | Chrome の翻訳機能をオンにする |
| ログインでコードを聞かれる | 認証アプリの 6 桁の数字を入力（毎回必要なことも） |
| 何を書けばいいか分からない | 既存のメモの真似をするのが一番早い |

慢性的に分からなくなったら、無理に進めずに声をかけてください。壊れて困るものはここにはありません。
