# キャラ画像（マスコット）で参考画像レベルの可愛さにする

テンプレートには **各行にキャラ画像を差し込むスロット**（アート列）が用意されています。
`assets/mascots/<キー>.png` を置くと、その行に**自動で表示**されます（コード変更は不要）。
参考にいただいた「星座ごとのキャラ（カニ・ライオン…）」の可愛さは、この方法で再現します。

> なぜ画像なのか：あの手描き風の動物キャラは**AI画像生成で作るイラスト素材**です。
> コード（SVG）で12種の動物を綺麗に描くのは非現実的なので、**一度だけ画像を作って使い回す**のが正解です。
> 一度作れば、以降すべての日の動画で自動的に使われます（量産と両立）。

---

## 手順

1. 下の「ファイル名一覧」のキーで、**正方形・背景透過(PNG)** のキャラ画像を用意する。
   - 画像生成AI（例：Midjourney / DALL·E / Stable Diffusion / Adobe Firefly など）でOK。
   - **全キャラを同じスタイル・同じ画風**で作るのがコツ（統一感＝可愛さ）。
2. `assets/mascots/` に、**キー名そのままのファイル名**で保存する（例：`cancer.png`）。
3. いつも通り生成するだけ：
   ```bash
   python scripts/make.py --date 2026-08-01 --days 30 --bgm assets/bgm/loop.mp3
   ```
   画像があるキーの行に、キャラが自動で表示されます。

推奨仕様：**512×512px 以上／正方形／背景透過／余白すこし**。表示は96px（少数行は132px）に自動縮小されます。

## スタイル指定の例（プロンプトのひな型）

全キャラで**この共通文**を使い、`___` の部分だけ差し替えると画風が揃います。

```
かわいいパステルカラーのちびキャラ、___、丸くてぷにっとした2頭身、
やわらかい水彩＋クレヨン風タッチ、ほっぺにピンクの頬紅、キラキラの目、
白背景（切り抜き用に背景透過）、ステッカー風、中央に1体だけ、影は控えめ
--- 英語なら: cute pastel kawaii chibi ___, chubby 2-head-tall, soft watercolor
crayon texture, pink blush cheeks, sparkly eyes, sticker style, single character
centered, transparent background
```

`___` に入れる被写体の例は下表。

## 補足
- **一部だけ**置いてもOK（あるキーだけキャラ表示、無い行は今まで通りスッキリ表示）。
- ペア系（`blood_pair` / `zodiac_pair`）は左に2つのバッジを出すため、キャラ列は使いません。
- ラッキーアイテムのアイコン（クッキー等）も出したい場合は、同じ仕組みで拡張できます（`templates/ranking.html` の `art` 部分を参照）。相談ください。
