# 戦略メモ：再生数マネタイズの「現実」と伸ばし方

最初に正直な話をします。作ったものを気持ちよく使うためにも、期待値を正しく合わせておくのが大事だからです。

---

## 1. 「再生数だけで不労所得」はそのままでは成立しにくい

TikTok で再生数からお金が入る主な仕組みは **Creator Rewards Program（旧 Creativity Program）** です。
2026年時点の一般的な参加条件はおおむね次の通りで、**どれも最初のハードルが高い**です（※最新条件はアプリ内で必ず確認してください。国・時期で変わります）:

- フォロワー **1万人以上**
- 直近30日の動画再生 **10万回以上**
- 18歳以上・対象国・オリジナル動画
- **1分以上の動画**が報酬対象（短い動画は対象外になりやすい）

つまり、

- **収益が発生するまでに数ヶ月かかる**のが普通。最初の半年は「積み上げ期間」で、収益ゼロ〜数百円のつもりで。
- 単価も高くなく、日本だと **1万再生あたり数十〜数百円規模**と言われます（変動します）。月に安定した金額にするには、**継続的に数十万〜数百万再生**を回す規模が必要。
- だからこそ「**半年毎日投稿**」という判断は正しい方向です。ただし報酬は"後からついてくる"もので、"貼っておけば入る"性質ではありません。

**結論**：この企画は「不労所得」ではなく「**半年かけてアカウントを資産化し、その後に収益が乗ってくる**」プロジェクトとして進めるのが現実的です。作業を仕組み化（＝このキット）して"労力あたりの本数"を最大化するのが勝ち筋です。

---

## 2. 静止画スライド占いの「落とし穴」と対策

今回のような「表を見せるだけ」の動画は量産に向く一方、伸び・収益の両面で弱点があります。先回りして潰します。

| 落とし穴 | なぜ問題か | 対策（このキットでの実装/運用） |
|---|---|---|
| **オリジナル性が低いと判定** | Creator Rewards は使い回し・自動生成っぽい低労力動画を報酬対象外にしがち | ①毎日中身を変える（本キットは日替わりで内容が変わる）②**アプリ内で自分の声のナレーションやトレンド音源を足す**③文字コメントを日々変える |
| **1分未満だと報酬対象外** | 静止画1枚だと数秒で終わる | 動画を **60秒以上**にする運用（下記） |
| **静止画1枚は離脱が早い** | 最初の1秒で"もう分かった"と思われスワイプされる | 「あなたは何位？」など**続きが気になる見せ方**、ランキングを**下位→上位で1枚ずつめくる**構成にする |
| **無音・非トレンド音源** | 発見(おすすめ)に乗りにくい | **TikTok内のトレンド音源／商用楽曲ライブラリ**を使う（リーチと著作権の両取り。詳細は workflow.md） |
| **参加のフックが無い** | コメント・保存が伸びず拡散しない | 「コメントで自分の星座を教えてね」「保存して1日持ち歩いて」を毎回入れる（キャプション自動生成に組込み済み） |

### 「静止画だけど1分以上・飽きさせない」おすすめ構成
本キットの1枚画像をベースに、次のどれかで尺と維持率を稼ぐのが現実的です:

1. **12位→1位を1枚ずつ公開**（各4〜5秒＝合計60秒前後）。「1位は最後まで見てね」で維持率を稼ぐ。
   → 発展として、ランキングを分割書き出しする拡張は `templates/` を複製して対応可能。
2. **1枚を表示しつつ自分の声で読み上げ**（ナレーション）。オリジナル性・維持率・尺すべてに効く。
3. まずは**8〜15秒のループ**で本数と投稿習慣を優先し、伸びてきたら①②に寄せる。

> 迷ったら「まず毎日出す（8〜15秒）→ 2〜3週間でデータを見る → 伸びた型を1分版に育てる」で十分です。

## 3. 再生数を回すための実務チェックリスト

デザインや内容以上に、**運用の型**が再生数を決めます。

- **最初の1秒**：タイトルを画面上部に大きく（本テンプレは対応済み）。「今日の運勢ランキング」と一目で分かる。
- **音**：トレンド音源を当てる（無音NG）。占い×おしゃれ/エモ系のBGMが相性◎。
- **フック文（キャプション冒頭）**：「1位は◯◯座！あなたは何位？」— 生成キャプションに自動で入ります。
- **ハッシュタグ**：`#占い #今日の運勢 #星座占い #占いランキング #fyp #おすすめにのりたい` を基本に、当たったタグを残す。多すぎ注意（5〜8個）。
- **投稿時間**：フォロワーが見る時間帯（朝の通勤7〜9時／昼12時／夜20〜23時）。占いは**朝が特に強い**（"今日の運勢"を朝に見る）。
- **投稿頻度**：1日1本を厳守。慣れたら朝夜2本もテスト。
- **参加導線**：コメント欄で「自分の星座/血液型」を言わせる → コメント数が伸びると露出が伸びる。
- **プロフィール**：一貫したテーマ（占い専門）だと関連表示に乗りやすい。アイコン・ハンドルも占いで統一。

---

## 4. 続けるかの判断（KPIと撤退ライン）

半年は"仕組みで淡々と出す"のが前提。ただし手応えは数字で見ます。

- **2週間**：平均再生・保存率・コメント率を記録。**伸びた投稿の"型"を特定**（テーマ/構成/音）。
- **1ヶ月**：伸びた型に寄せる。フォロワー増加ペースを見る。**月+300〜500フォロワー**あればペース良好。
- **3ヶ月**：1万フォロワー／30日10万再生の**収益化ラインが見えているか**。届いていなくても、伸びる型が固まっていれば継続価値あり。
- **撤退ではなく方針転換**：全く伸びないテーマは差し替え、伸びる音源・時間帯に全振り。"やめる"より"当たりに寄せる"。

## 5. 収益の複線化（半年後の伸ばし方・参考）

今回は「純粋に再生数」を目標にしていますが、アカウントが育つと収益源は自然に増やせます（将来の選択肢としてメモ）:

- **TikTok LIVE**（ギフト）… フォロワーが増えたら占いライブは相性が良い。
- **アフィリエイト**（パワーストーン/占いアプリ等）… プロフィールリンクから。
- **他プラットフォーム展開**… 同じ素材を YouTube ショート／Instagram リールに**そのまま流用**（本キットの縦型MP4はどれもそのまま使える）。再生の分散＝収益の分散。

> 今は「毎日出す仕組み」を回すことに集中でOK。複線化は"資産"ができてからで間に合います。
